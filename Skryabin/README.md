
# Лабораторная работа №1
"Программа" просто демонстрирует возможности js в связке с HTML

# -------- Запуск --------
    1.Скачайте папку с проектом.
    2.Найдите файл `index.html` и откройте его двойным кликом в любом современном браузере
    3.На главной странице будут ссылки для перехода на первое и второе задания

# -------- Что внутри --------
    1.page1.html — первый экран (счётчик, квадраты, работа с фото)
    2.page2.html — второй экран (обработка событий, картинка Громилы, клонирование)
    3.spec.md — полная функциональная спецификация
    4.use-case.png — диаграмма вариантов использования

# -------- Как пользоваться --------
    Просто. Кликаете по кнопочкам и наблюдаете за происходящим

# -------- Ограничения --------
    Как таковых нет. Но оно не будет показываться на браузере, если нету браузера.
    Незнаю как это будет отображаться на старых браузерах, советую все же скачать свежий браузер.
